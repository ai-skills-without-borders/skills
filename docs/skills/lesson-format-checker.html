Lesson & Notebook Format Checker

Checks lesson plans and Jupyter assignment notebooks against a house-style profile and applies only approved fixes.

MaturityDraft
Version0.1.0
Runs codeOptional scripts
Maintained byAmit Shraga, PhD (Weizmann Institute of Science)

When to use it

Checks a lesson plan, session plan or course/assignment Jupyter notebook against an institution's house-style format profile, reports every deviation with a proposed fix, and applies only the fixes the educator approves, in a new copy. Use whenever an educator uploads or points to a lesson plan, session plan or assignment notebook (.ipynb, .md, .docx) and asks to check, review, audit, lint, validate or "fix the format" of it, asks whether it follows the house style or template, wants timing checked against the session length, or wants a new lesson or notebook created in the standard structure. Ships with two example profiles (a Jupyter assignment-notebook profile and a generic lesson-plan profile) that institutions copy and adapt. Does not judge pedagogical quality and is not for generic data-analysis notebooks unrelated to teaching.

Use it to

  • Check a lesson plan's format
  • Lint an assignment notebook
  • Check session timing
  • Create a lesson in the standard structure

Pedagogical basis

What each rule rests on. Research Standard Practice — rules labelled Practice are local conventions your institution may change. All principles and references.

Rule in this skill Basis Source

Model answer for each question; facilitator notes separate from learner text Research + Practice Feedback is essential for learning from questions — Larsen, Butler & Roediger, 2008, Medical Education 42:959–966; separation is local practice
Deliberate keep/strip choice for code cells Research Worked examples for first exposure, then fading to independent work — Sweller, 1988
