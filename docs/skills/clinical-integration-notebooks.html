What it does

Use it to

  • Create clinical integration tasks for my course
  • Find an NEJM case that fits the methods my students have learned
  • Build a case-based team assignment from my course schedule
  • Make an integration session where students apply lab methods to a patient case
  • Generate this year's integration notebooks from my assignments and dates
  • Pick a clinical case for a physician-scientist methods course

You bring

  • Course assignments or materials: a zip of notebooks, slides or a methods book
  • Dates: the date of each integration task, and when each method is taught
  • Course profile (first run only): course name, session length, group size, presenters, language
  • Optional: session themes, and cases used in past years so they are not repeated
the skill

You get

  • Student notebook (HTML): learning goals, case background, a handout that hides the diagnosis, a timed session plan and discussion questions
  • Instructor key (HTML): verified citation, diagnosis, matched methods with their teaching dates, Q&A questions and a debrief note
  • Summary table: task date, method window, case chosen, matched methods
  • profile.json for reuse next year (first run only)
The description the AI reads

Builds clinical integration sessions for a methods-based course. For each integration task date, it finds a recent NEJM clinical case (MGH Case Records, or Clinical Problem-Solving if needed). The case has to fit methods students have already learned, including at least one taught since the previous task. It then writes a student-facing session notebook and an instructor key. Students don't diagnose the patient. Working in small teams, they choose course methods and combine them into a plan a physician-scientist could use to investigate the disease mechanism. Selected students then present one method each in a chalk talk and answer questions. Use it when you teach methods in separate sessions (lab techniques, omics, imaging, data analysis) and want recurring sessions where students apply them together to a real patient. This works best in preclinical, MD-PhD or biomedical graduate courses. It is also useful when you need a fresh case each year without the hours of searching for one.
