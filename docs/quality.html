How skills are tested and approved

A skill is only as good as the evidence that it works somewhere other than where it was written. Every skill shows its level, where it has been tested, and who reviewed it.

Maturity levels

A skill moves up only with evidence attached. It moves down if a tool change breaks it.

  1. DraftWritten or generalized, passes the automatic checks, not yet used for real teaching in this form.
  2. Tested at originUsed for real teaching at the institution that wrote it, with a usage report.
  3. Tested elsewhereUsed successfully at one or more other institutions, each with a usage report.
  4. ReviewedTested elsewhere and independently reviewed with the checklist by an educator from another institution.

What is checked automatically

Every change runs the library's build before anyone reviews it.

  • The skill's name, description and card are complete and consistent.
  • Every file the skill refers to exists.
  • No product-specific instructions that would stop it working in other AI tools.
  • Skills that include scripts say so, and work by reading where code can't run.
  • Maturity claims above "tested at origin" have usage reports or reviewers listed.
