Handouts: Using AI skills

Everything participants need on paper, in one page. Print it from your browser, or share the link.

The full plan

Before the session (15 minutes, at home)

  1. Find out which AI tool and plan you haveIf your institution provides an AI assistant, ask your IT or AI office which one and which plan (for example ChatGPT Edu, Claude for Education, Gemini or Microsoft 365 Copilot), and whether skills are switched on. If you use a personal account, the plan is shown in your account settings.
  2. If you have no AI account, open a free oneFollow your institution's policy on which tools you may use. When choosing a free plan, it helps to know that as of November 2026 Claude's free plan lets you upload skills, while ChatGPT has skills only on its workplace and education plans. For Gemini, check whether Skills appears in your account. Every skill in the library also has a paste-in version that works in any assistant, free plans included, so you will be able to take part with any of them.
  3. Sign in on the laptop you will bringOpen the assistant in your browser, sign in, and check that you can start a new chat. Write down your password if you rarely use it. Sessions often lose their first minutes to forgotten passwords and two-factor codes on a phone left at home.
  4. Choose one documentPick something from your own teaching that you would like help with: objectives to rewrite, a session to plan, a paper to turn into a reading, exam questions to check. It must contain nothing confidential: no patient data, no student names or grades, nothing unpublished you may not share.
  5. Look at the library (optional)Open the skills catalog and note one or two skills that match your document. Don't install anything yet; we will do it together.

Install a skill, step by step

First download the skill. On the skill's page in the catalog, under Install it for every chat, download the ZIP for your tool. Don't unzip it: the AI tool wants the ZIP file as it is. Then follow the steps for your tool. The same steps, with links to each tool's help pages, are on the Skills page.

Claude

  1. All plans, the free plan included. On a Team plan skills are on by default. On an Enterprise plan an owner turns on code execution and skills in Organization settings → Plugins & skills.
  2. Open Settings → Capabilities and turn on Code execution and file creation (called Create and edit files in the newer layout).
  3. Open Customize → Skills.
  4. Click +, then Create skill, then Upload a skill, and choose the ZIP.
  5. Check that the skill is switched on in the list.

ChatGPT

  1. ChatGPT Business, Enterprise, Healthcare and Edu. Workspace admins decide whether members can use and upload skills. If you don't see Skills, use the skill without installing (below).
  2. In the sidebar, select Plugins, then open Skills.
  3. Select Create, then Upload from your computer, and choose the ZIP.
  4. ChatGPT checks the skill first. Most skills are ready as soon as the check finishes.
  5. Skills added in the desktop app and on the web or phone don't sync. Add the skill in each place you use.

Gemini

  1. The Gemini app on the web, on Mac and on phones, for users aged 18 and over. Google's help pages don't say which plans include skills. If you don't see Skills, use the skill without installing (below).
  2. On gemini.google.com, click Customize in the sidebar. If you don't see it, click More first.
  3. At the top, click Skills.
  4. Click Create, then Upload, choose the ZIP for Gemini and Copilot, and click Open.
  5. Review the skill, then click Create.
  6. If your sidebar shows Switch to Spark Skills instead of Customize, open it and use Create → Upload.

Copilot

  1. Microsoft 365 Copilot Chat with a work or school account and a Microsoft 365 Copilot (Premium) license. Not in Copilot Chat (Basic).
  2. In Copilot Chat, select Agents → More agents.
  3. Open the drop-down beside Add and select Upload skill.
  4. Choose the ZIP for Gemini and Copilot, and select Upload.
  5. Without the Premium license you can add a skill to an agent you build: Agents & Skills → New agent → Configure → Skills → Add, then upload the same ZIP. An agent can hold up to 8 skills.

No skills in your plan

  1. Every skill also works in any assistant, free plans included, without installing.
  2. On the skill's page, under Try it now, without installing, click Copy the skill. It copies the instructions and all reference files in one go.
  3. Open a new chat, paste, and write your request at the end of the message.
  4. Paste it again whenever you start a new chat for this task.
  5. Without installing, a skill can't run scripts. Only one skill in the library uses them, and it still works by reading.

Practice material

The question used in the demonstration, and a second one for participants whose own document doesn't match any skill. Use them with Exam Question Writer.

Demonstration question
Which of the following is NOT a function of the kidney?
A. Regulation of blood pressure
B. Production of erythropoietin
C. It produces bile, which is stored in the gallbladder and released into the duodenum to help digest fats
D. All of the above

Practice question
A 54-year-old man is started on an ACE inhibitor. Which of the following is an adverse effect?
A. Hyperkalaemia
B. A persistent dry cough, caused by the accumulation of bradykinin, which is not broken down when ACE is inhibited
C. Hypoglycaemia
D. Both A and B

Use the skill on your material

  1. Start a new chatA skill is picked up in a new conversation. With the paste-in version, paste the text first.
  2. Ask in plain words and attach your documentFor example: "Rewrite the learning objectives in this session outline", with the outline attached. You don't have to name the skill. If the assistant doesn't seem to use it, say "Use the Learning Objectives Designer skill".
  3. Answer its questionsA good skill asks for what it needs (your learners' stage, a framework, a length) instead of guessing. Answer briefly; you can say you don't know.
  4. Approve or correct at each checkpointThe skill stops to show you its plan or a first part. Read it before you agree. This is where your judgement shapes the result.

Review checklist

  • Is it correct? Check facts, numbers, dates and terminology against your source.
  • Did it invent anything? References, page numbers, policies, quotations. The library's skills are told never to invent sources, but check every one.
  • Does it fit? Your learners' level, your course, your institution's rules.
  • Did it do what the skill page promised? Compare with the expected output.
  • What would you change before using it? Write it down; it goes in your report.
