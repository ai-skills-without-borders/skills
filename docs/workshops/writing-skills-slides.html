Part 1

Anatomy of a skill

Writing AI skills4 / 20
Speaker notesWe take a published skill apart.

A skill is a text file

SKILL.md

name: …description: what it does, and when
## Step 1 …## Step 2 …
Stop: show the plan, wait for approval
## Output
## Limitations
  1. Name and description: read first, to decide when to use it
  2. Steps, in order
  3. Checkpoints where the educator approves
  4. The output, exactly
  5. Limitations, and what to always check
Writing AI skills5 / 20
Speaker notesOpen the chosen skill's SKILL.md on GitHub and scroll through it with the room, pointing at each part.

The description decides whether it is ever used

Too vague

  • "Helps with teaching."
  • "A useful tool for objectives."

What, when, in the user's words

  • "Writes and fixes learning objectives for a course or session."
  • "Use when an educator asks to write, check or map objectives."
Writing AI skills6 / 20
Speaker notesThe assistant compares the user's request with every description. Say what the skill does, when to use it, and the words people actually use.

Six parts, for every skill

PurposeWhat it does, and when to use it
InputsWhat the user provides, and what to ask for
InstructionsSteps, standards, checkpoints
Expected outputSections, format, length
Success criteriaHow you know it's good enough
LimitationsWhat it doesn't do, what to check
Writing AI skills7 / 20
Speaker notesEvery skill in the library follows these six parts. They are also the fields of the submission form, so writing them now saves time at the end.

Common mistakes

Avoid

  • A whole job in one skill
  • Guessing when input is missing
  • "Make it good" instead of a standard
  • No point where the educator approves

Instead

  • One task, one clear result
  • Ask for what's missing
  • Name the standard and its source
  • Stop for approval where judgement matters

Speaker notesThese four cover most of the problems we see in first drafts.

A good first task

  • You do it often, so it saves real time
  • You do it well, and know what good looks like
  • One task, with a clear result
  • Others do it too, at other institutions
  • No confidential data needed

Part 2

Write and test

Writing AI skills11 / 20
Speaker notesThe main block. Thirty minutes writing, fifteen testing.

Two ways to draft

Write it yourself

  • Fill in the six parts
  • Write what you do, in order
  • Turn every "it depends" into a question

Let AI interview you

  • Paste the drafting prompt
  • Answer one question at a time
  • Correct the draft it writes
Writing AI skills12 / 20
Speaker notesBoth work. The interview is faster for most people, but read the draft carefully; it's your expertise, and the AI will fill gaps with plausible guesses if you let it. The prompt is on the workshop page.

The test loop

  1. New chat, nothing carried over
  2. Paste the skill, then "follow the skill above"
  3. Fresh input, not the example you wrote from
  4. Judge against your success criteria
  5. Fix the instruction, not the output, and repeat
