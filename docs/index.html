The same request to an AI assistant, about the same flawed exam question: once on its own, once following the Exam Question Writer skill.

The question

Which of the following is NOT a function of the kidney?

  1. A. Regulation of blood pressure
  2. B. Production of erythropoietin
  3. C. It produces bile, which is stored in the gallbladder and released into the duodenum to help digest fats
  4. D. All of the above

Without the skill

Issues: negative wording, "All of the above", and option C is much longer than the others.

Revised: Which hormone is produced by the kidney?

A. Erythropoietin ✓ B. Insulin C. Glucagon D. Cortisol

  1. Changed what the question tests, without asking
  2. No objective, no check of the answer against a source

With the skill

Before I revise it: is this formative or summative? Which objective does it test? What source should the key agree with?

Flaw check: 4 failed (negative stem, "All of the above", longest-option cue, mixed option forms).

Minimal fix, same objective. Key checked against your lecture 4.

  1. Asks before changing anything
  2. Names each flaw against a checklist
  3. Keeps the objective, checks the key

Why it matters

Expertise is unevenly shared

Experienced educators and education specialists are concentrated in a few well-resourced institutions. Most programs, in most countries, build every course on their own.

Skills open it up

A skill turns that know-how into a tool any educator can use: open licence, open format, no programming, and a paste-in version for free AI plans.

Knowledge flows both ways

Any educator, at any institution, can adapt a skill, report how it went, or share their own. Every use makes the library better for the next person.

Read why we started this project or see the community map

What every skill is designed to do

  • Flag gaps instead of inventing. Skills tell the AI to ask, or to leave a visible placeholder, rather than make up sources, figures or framework wording.
  • Leave the decisions to you. The skill proposes and stops for your approval. You review every output before it reaches a learner.
  • Show their evidence. Each rule is labelled with what it rests on, and each skill shows where it has been tested.
