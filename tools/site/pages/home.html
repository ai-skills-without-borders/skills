Commitments built into every skill

  1. Never invents sources, figures, names, dates or framework wording. Gaps become visible placeholders or questions.
  2. You decide. The skill proposes; the educator approves. Competency maps are proposals for faculty review.
  3. Says it used AI. Outputs carry a one-line AI-assistance statement in your institution's wording.
  4. Keeps data private. No identifiable patient or learner data, ever.
  5. Works in any assistant. Skills that run code say so, and still work by reading where code can't run.
  6. Shows its evidence. Each rule is labelled with what it rests on, and each skill shows where it has been tested.
