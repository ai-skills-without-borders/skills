# Installing the skills

The install steps for Claude, ChatGPT, Gemini, Microsoft 365 Copilot and Claude Code are on the
[Skills page](https://ai-skills-without-borders.github.io/skills/skills.html#install), with links to each tool's own help pages.

They are written in one place, [install.yaml](install.yaml), which feeds the Skills page, the skill pages, and the
workshop handouts and slides. To correct a step, edit that file only.
