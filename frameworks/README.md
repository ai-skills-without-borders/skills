# Competency frameworks

Several skills (`learning-objectives-designer`, `syllabus-builder`) map teaching to a competency framework. The skills never reproduce framework wording from memory: **you supply the framework**, and the skill uses its exact IDs and wording.

## Ways to supply a framework

1. **Upload or paste the official document** (PDF, Word, web page text) in the conversation. Simplest.
2. **Use a framework file** in the format below, so the same framework is reused consistently across courses. Store it in your institution's copy of the library or attach it each time.

## Framework file format

A Markdown file with a short header and a table of the lowest-level items. See [`_template.md`](_template.md) and the fictional example [`example-institutional-framework.md`](example-institutional-framework.md).

## Frameworks educators commonly use

| Framework | Publisher | Notes |
|---|---|---|
| Foundational Competencies for Undergraduate Medical Education (2024) | AAMC, AACOM, ACGME | Replaces the AAMC PCRS. The AAMC also offers a Medical School Program Objective Tracker for member schools |
| GREAT MD-PhD Competencies Development Toolkit | AAMC GREAT Group | 16 competencies in four domains, with a milestone-based assessment tool, for physician-scientist training |
| AI Competencies Across the Learning Continuum (2026) | AAMC | Three developmental tiers; for AI-related teaching |
| Core EPAs for Entering Residency (2014) | AAMC | Under re-evaluation since the 2024 Foundational Competencies |
| Institutional EPAs and competencies | Your program | Usually the most important one for your courses |

**Licensing:** check whether a framework's license allows redistribution before adding its full text to a shared repository. If not, keep the file in your institution's private copy, or contribute a *pointer file* (header + link, no item text).

## Pointer file example

```markdown
# Framework: Foundational Competencies for Undergraduate Medical Education
- Publisher: AAMC, AACOM, ACGME
- Version: 2024
- Get it from: https://engage.aamc.org/UME-Competencies-AAMC-ACGME-AACOM
- Item text: not included — upload the official document when mapping.
```
